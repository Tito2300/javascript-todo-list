# JavaScript To-Do List

A clean, responsive to-do list application built with vanilla HTML, CSS, and JavaScript.

## Features
- Add tasks
- Mark tasks complete or incomplete
- Delete tasks
- Clear completed tasks
- Remaining-task counter
- localStorage persistence
- Responsive design

## Built With
HTML5, CSS3, JavaScript (ES6), and Browser Local Storage.

## Run Locally
Open `index.html` in a web browser. No dependencies are required.

## What I Practiced
DOM manipulation, event listeners, arrays, functions, conditional rendering, browser storage, responsive CSS, and accessibility basics.
